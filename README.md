# Construcciones Florin

Web inicial en Next.js + Tailwind CSS. Incluye portada, servicios, catálogo, proyectos y formulario de presupuesto que prepara un mensaje de WhatsApp.

## Ejecutar en Mac
1. Instala Node.js LTS si aún no lo tienes: https://nodejs.org/
2. Abre Terminal en esta carpeta.
3. Ejecuta `npm install`
4. Ejecuta `npm run dev`
5. Abre http://localhost:3000

## Antes de publicar
- Sustituye teléfono y correo de ejemplo en `lib/site.ts`.
- Sustituye los modelos y proyectos de demostración por datos reales.
- Las fotos de Unsplash son ilustrativas; cambia por fotografías propias con autorización.
- Añade tu dominio en `.env.local` a partir de `.env.example`.
- Configura Google Analytics 4 con `NEXT_PUBLIC_GA_ID`.
- Revisa aviso legal, privacidad y cookies con asesoramiento adecuado.
- Despliega en Vercel y conecta Google Search Console.

No publiques cifras, ubicaciones, obras ni testimonios ficticios como si fueran reales.
